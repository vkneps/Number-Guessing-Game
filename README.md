# 🎲 Number Guessing Game / Угадалка чисел

Простая консольная игра на Python, в которой пользователь угадывает случайное число, сгенерированное компьютером.

## 🛠 Особенности и функции
- Выбор правой границы угадывания ($n$).
- Подсчёт количества потраченных попыток.
- Обработка некорректного ввода («защита от дурака»).
- Возможность сыграть повторно без перезапуска программы.

## 🚀 Как запустить
1. Установите Python 3.
2. Скачайте файл `main.py`.
3. Запустите его в консоли:
   ```bash
   python main.py
